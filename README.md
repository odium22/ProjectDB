# ProtectDB — GUI для управления базой данных

Серый минималистичный интерфейс (WinForms/.NET 8, SQLite) для проектирования и управления БД с разграничением прав.

## Возможности
- Вход пользователей (роли: admin / user / viewer)
- Проектирование БД: создание таблиц
- Просмотр схемы данных и связей
- Разграничение прав по ролям
- Health checker + просмотр БД
- CRUD данных с учётом прав
- Тестирование: проверка запуска и валидности данных
- Журнал действий пользователей

## Запуск (C# — основная версия)
```
dotnet run --project db_app_csharp
```
Требуется .NET 8 SDK. Вход по умолчанию: admin / admin

## Запуск (Python-версия)
```
cd db_app
python app.py
```

## Структура
- `db_app_csharp/` — C# WinForms (основная)
  - `Database.cs` — слой БД, права, health checker
  - `App.cs` — GUI
- `db_app/` — Python/Tkinter (альтернативная)
